📋 블로그에 붙여넣기

아래 버튼을 누르면 글과 사진이 함께 복사됩니다. 네이버 블로그 글쓰기 화면에서 붙여넣기(Ctrl+V) 하세요.

  1. 아래 글+사진 전체 복사를 누릅니다
  2. 네이버 블로그 → 글쓰기를 엽니다
  3. 본문 칸을 클릭하고 Ctrl+V (Mac 은 ⌘V)
  4. 사진은 네이버가 자동으로 받아 옮깁니다 — 잠깐 기다리면 됩니다
원본 화질로 직접 첨부하고 싶다면 — 사진 전체 내려받기로 ZIP 을 받아 압축을 푼 뒤, 블로그 글쓰기의 [사진] 버튼으로 번호 순서대로 첨부하고 글은 글만 복사로 붙여넣으세요.
