설명서를 고치는 법  (글·그림 둘 다)

━━ 0. 고치고 나서 확인하는 법 ━━ 이것부터 ━━

  명령 프롬프트에서 C:\aircon-report 로 간 뒤

      npm run manual

  이 한 줄이 두 가지를 해 줍니다.
    · 틀린 곳을 짚어 줍니다 (따옴표 빠짐, 설명 없음, 그림 파일 없음, 용량 큼)
    · manual-preview.html 을 만들어 줍니다 → 더블클릭하면 브라우저에서 보입니다

  고칠 때마다 이 명령을 다시 돌리고 브라우저에서 F5 를 누르면 됩니다.
  (앱을 다시 빌드할 필요 없습니다. 빌드는 다 끝난 뒤 한 번만)

  아직 안 채운 그림 자리 목록을 보려면:   npm run manual -- --todo

━━ 1. 글 고치기 ━━

  파일 하나만 만지면 됩니다:  www\js\manual_data.js
  메모장으로도 되지만, VS Code 같은 편집기가 따옴표 짝을 색으로 보여 줘서 편합니다.

  안이 이렇게 생겼습니다. **작은따옴표 사이의 글자만** 바꾸세요.

      { h: '작업명 — 현장 이름을 적습니다',
        d: '「○○아파트 101동」처럼 나중에 봐도 어딘지 알 만한 이름이면 됩니다.',
        img: [{ src: '', shape: 'tall', cap: '작업 탭 위쪽 화면.' }] },

    t   큰제목 (목록에 보이는 줄)
    s   큰제목 아래 한 줄 설명
    h   단계 제목
    d   단계 설명          ← **굵게** 로 감싸면 굵은 글씨가 됩니다
    tip 파란 상자 한 줄
    cap 그림 아래 설명

  ☠️ 조심할 것 세 가지
    · 따옴표(')를 지우거나 더하지 마세요. 짝이 안 맞으면 설명서가 통째로 안 뜹니다.
    · 글 안에 ' 를 쓰고 싶으면 「 」 나 " 를 쓰세요. (예: 「완료」)
    · 줄 끝 쉼표(,)를 지우지 마세요.
  → 셋 다 npm run manual 이 몇 번째 줄인지 짚어 줍니다. 겁내지 말고 고치세요.

━━ 2. 그림 넣기 ━━

  1) 스크린샷 파일을 이 폴더에 복사합니다.   예: tabs-1.png
  2) manual_data.js 에서 해당 칸을 찾아 src 에 **파일 이름만** 적습니다.
       { src: 'tabs-1.png', shape: 'tall', cap: '앱을 처음 켠 화면' }
  3) cap 은 그림 아래 붙는 설명입니다. 지금 적혀 있는 문구는
     "무슨 화면을 찍어 와야 하는지" 메모이니, 넣을 때 짧게 고치거나 지우세요.
     (좁은 칸에서는 세 줄까지만 보입니다)

━━ 3. 어떤 비율로 찍나 ━━

  빈 액자 안에 어느 쪽인지 적혀 있습니다.

  [세로 화면]      휴대폰 화면을 통째로 찍으면 됩니다. 자르지 마세요.
                   글 오른쪽에 작게 붙고, 사용자가 누르면 크게 볼 수 있습니다.

  [가로로 잘라서]  설명하는 부분만 좌우로 길게 잘라 주세요.
                   예: "[카메라] [파일] 두 버튼이 보이게"
                   → 그 줄만 남기고 위아래를 잘라냅니다.
                   (갤러리 → 편집 → 자르기)

  ⚠️ 비율을 잘못 맞춰도 괜찮습니다. 앱이 그림을 불러와서 세로인지 가로인지
     스스로 판단해 알맞게 놓습니다. 위 구분은 "무엇을 찍어 올지" 안내입니다.
  ⚠️ shape: 'tall' 은 **빈 액자 모양**만 정합니다. 지우거나 틀려도 결과는 맞습니다.

━━ 4. 주의 ━━

  · src 가 비어 있으면 그 자리는 아예 안 그려집니다.
    그림을 하나도 안 넣은 채로 배포해도 괜찮습니다.
  · 파일 이름이 틀리면 앱에서는 그 그림만 조용히 사라집니다.
    → npm run manual 이 이름을 대 주니 그걸로 찾으세요.
  · 사진 용량이 곧 앱 용량입니다. 한 장 300KB 아래로 줄이세요.
  · 같은 화면을 두 곳에서 쓰면 파일 하나를 두 번 적으면 됩니다.
    (예: '설정 탭을 연 화면' 은 1부와 6부에 두 번 나옵니다)
  · 다 끝나면 평소대로 빌드하세요. manual-preview.html 은 앱에 안 들어갑니다.
