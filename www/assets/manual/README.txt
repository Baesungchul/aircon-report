설명서를 고치는 법


━━ 제일 쉬운 방법 — 화면에서 고치기 ━━━━━━━━━━━━━━━━━━

  명령 프롬프트를 열고 딱 두 줄만 칩니다.

      cd C:\aircon-report
      npm run manual:edit

  그러면 주소가 뜹니다.  http://localhost:8787
  브라우저 주소창에 그대로 치면 **편집 화면**이 열립니다.

  여기서 하는 일은 세 가지뿐입니다.

    · 글 고치기    칸에 대고 그냥 고치면 됩니다. 저장 버튼 없습니다.
    · 그림 넣기    점선 상자에 사진을 끌어다 놓습니다.
                   상자를 눌러서 파일을 골라도 되고,
                   복사한 사진은 상자를 누르고 Ctrl+V 해도 됩니다.
    · 확인하기     오른쪽 위 [미리보기] 를 누르면 실제 설명서 모양이 뜹니다.

  위쪽에 「그림 68 / 77」처럼 얼마나 채웠는지 나옵니다.
  왼쪽 ‹ › 로 칸을 넘기거나, 가운데 목록에서 골라 이동합니다.

  ⭐ 아직 안 넣은 그림이 어디인지 바로 찾습니다
     칸 목록 아래에 노란 띠가 있습니다.  「아직 안 넣은 그림 9곳」
       · [다음 빈 자리] 를 누르면 그 자리로 바로 내려가 잠깐 깜빡입니다.
         계속 누르면 순서대로 한 곳씩 돌고, 끝까지 가면 처음으로 돌아옵니다.
       · [목록] 을 누르면 빈 자리가 전부 줄줄이 나옵니다. 어느 부, 어느 큰제목,
         몇 단계인지 적혀 있고 한 줄을 누르면 그 자리로 갑니다.
       · 칸 고르는 목록에도 「6. 사진 정리하기  ○1」처럼 몇 개 비었는지 붙습니다.
       · 빈 상자 안에는 「빈 자리 5 / 9」처럼 전체에서 몇 번째인지 적힙니다.
     사진을 하나 넣으면 숫자가 바로 줄어듭니다. 띠가 사라지면 다 채운 것입니다.

  ⭐ 사진을 여러 장 한꺼번에 담아두기 (폰에서 제일 편합니다)
     맨 위 [📥 사진 여러 장 담아두기] 를 누르면 갤러리가 **한 번만** 열립니다.
     거기서 찍어둔 캡처를 여러 장 골라 담으세요.
     그러면 화면 위에 사진 줄이 생깁니다.
       ① 사진 줄에서 넣을 사진을 한 번 누릅니다 (파란 테두리가 생깁니다)
       ② 아래에서 넣을 자리를 누릅니다 → 바로 들어갑니다. 갤러리가 안 열립니다.
     쓴 사진에는 ✓ 가 붙습니다. 같은 사진을 두 자리에 넣어도 됩니다.
     담아둔 사진은 PC 임시 폴더에 있다가 저절로 없어집니다 — 앱에는 안 들어갑니다.

  ⭐ 사진은 알아서 줄여서 넣습니다. 크기를 맞출 필요 없습니다.
  ⭐ 휴대폰으로 해도 됩니다.
     PC 와 같은 와이파이라면, 켤 때 같이 뜨는 http://192.168.…:8787 주소를
     휴대폰 브라우저에 치면 됩니다. 갤러리 사진을 바로 올릴 수 있습니다.

  끝낼 때는 명령 프롬프트 창에서 Ctrl+C.


━━ 어떤 화면을 찍어 오나 ━━━━━━━━━━━━━━━━━━━━━━━━━

  빈 상자마다 "찍어 올 화면 — …" 이라고 적혀 있습니다. 그대로 찍으시면 됩니다.

  · 화면 전체를 보여 주는 자리  → 휴대폰 화면을 통째로 찍습니다. 자르지 마세요.
  · 한 부분만 보여 주는 자리    → 그 줄만 남기고 위아래를 잘라냅니다.
                                  (갤러리 → 편집 → 자르기)

  비율을 잘못 맞춰도 괜찮습니다. 앱이 가로인지 세로인지 스스로 보고 알맞게 놓습니다.

  그림 아래 붙는 설명은 상자 옆 「그림 설명」 칸에서 고칩니다.
  지금 적혀 있는 문구는 "무엇을 찍어 올지" 메모이니, 넣은 뒤 짧게 고치거나 지우세요.


━━ 다 하고 나면 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  평소대로 빌드하면 됩니다. 따로 할 일 없습니다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  npm run manual          검사 + manual-preview.html 만들기
  npm run manual -- --todo   아직 안 채운 그림 자리 목록

  글 파일은 www\js\manual_data.js 하나입니다. 안은 이렇게 생겼습니다.

      { h: '작업명 — 현장 이름을 적습니다',
        d: '「○○아파트 101동」처럼 나중에 봐도 어딘지 알 만한 이름이면 됩니다.',
        img: [{ src: '', shape: 'tall', cap: '작업 탭 위쪽 화면.' }] },

    t 큰제목 · s 한 줄 설명 · h 단계 제목 · d 단계 설명(**굵게** 가능)
    tip 파란 상자 · src 그림 파일 이름 · cap 그림 아래 설명

  ☠️ 따옴표(')와 줄 끝 쉼표(,)를 건드리면 설명서가 통째로 안 뜹니다.
     틀리면 npm run manual 이 몇 번째 줄인지 짚어 줍니다.
     → 이래서 위의 편집 화면을 만든 겁니다. 웬만하면 그쪽을 쓰세요.

  · src 가 비어 있으면 그 자리는 아예 안 그려집니다. 그림 없이 배포해도 됩니다.
  · 사진 용량이 곧 앱 용량입니다. 한 장 300KB 아래로.
    (편집 화면으로 넣으면 알아서 맞춰 줍니다)
  · 그림을 뺐을 때 파일은 폴더에 남습니다.
    안 쓰는 파일은 npm run manual 이 이름을 알려 주니 그때 지우면 됩니다.
