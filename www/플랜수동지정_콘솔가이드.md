## 작업 B. Firestore 규칙 게시

규칙은 "누가 어떤 데이터를 읽고 쓸 수 있는지"를 정하는 곳입니다.
여기서 두 가지를 보장합니다.
- 관리자(나)는 아무 사용자의 등급을 바꿀 수 있다.
- 일반 사용자는 자기 등급(plan)이나 관리자권한(admin)을 스스로 못 올린다.

### B-1. 규칙 화면 열기
1. **Firestore Database** 화면에서 상단 탭 중 **규칙(Rules)** 클릭.
2. 편집창에 이미 규칙이 들어 있습니다. 그중 **`match /users/{uid}` 로 시작하는 블록**을 찾습니다.

### B-2. users 블록 교체
`match /users/{uid} { ... }` 블록 **전체**를 아래 내용으로 바꿉니다.
그리고 `isAdmin()` 함수는 맨 위 `match /databases/{database}/documents {` 바로 아래에 넣습니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // 관리자 판별 함수
    function isAdmin() {
      return request.auth != null
        && exists(/databases/$(database)/documents/users/$(request.auth.uid))
        && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.admin == true;
    }

    // 사용자 문서
    match /users/{uid} {
      allow read:   if request.auth != null;                 // 이메일로 상대 검색(공유·플랜관리)
      allow create: if request.auth.uid == uid
                    && !request.resource.data.keys().hasAny(['admin'])
                    && (!request.resource.data.keys().hasAny(['plan']) || request.resource.data.plan == 'free');
      allow update: if isAdmin()
                    || ( request.auth.uid == uid
                         && !request.resource.data.diff(resource.data).affectedKeys().hasAny(['plan','admin']) );
    }

    // ↓↓↓ 기존 coupons 규칙, shares, chats 등 다른 블록은 여기 그대로 두세요 ↓↓↓

  }
}
```

> 주의: 위 예시는 users 블록만 보여드린 것입니다.
> **기존에 있던 coupons / shares / chats 같은 다른 match 블록은 지우지 말고 그대로 두세요.**
> `isAdmin()` 함수와 `match /users` 블록만 위 내용으로 맞추면 됩니다.

2. "게시되었습니다" 뜨면 끝.

## 다 끝난 뒤 — 다른 사람 등급 올리는 법 (앱에서)
1. 앱 → 설정 → ⭐ 구독 → **🛠️ 사용자 플랜 관리**
2. 상대방 **이메일** 입력 → **검색**
3. 나온 카드에서 **무료 / 베이직 / 프로 / 마스터** 중 원하는 버튼 클릭 → 즉시 반영
4. 필요하면 그 사람도 **관리자 권한** 체크박스로 관리자 지정 가능

이제 콘솔 열 필요 없이 여기서 다 됩니다.
